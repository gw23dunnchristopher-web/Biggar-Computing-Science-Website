## Tips

- Paste any HTML code directly into your `.html` files — no extra CSS or JavaScript needed.
- For emoji icons (codes starting with `&#12...` or `&#127...`), browser support is excellent on all modern devices.
- You can also paste the icon character itself (✓, ☰, etc.) directly into HTML — modern text editors and browsers handle Unicode fine.
- To change colour or size of an icon, wrap it in a `<span>` with inline style:
  ```html
  <span style="color: green; font-size: 1.2em;">&#10004;</span>
  ```
