## Colourless SVG Icons — Database, Web Dev & Programming

These icons are drawn in SVG using `currentColor`, meaning they inherit whatever colour you set in CSS. They work at any size and look sharp on all screens. Paste the SVG block directly into your HTML wherever you want the icon to appear.

To resize or recolour, add `style="width:32px; height:32px; color:#153d64;"` to the `<svg>` tag.

### How to Use SVG Icons

Paste the SVG block directly into your HTML. To change size and colour:

```html
<!-- Blue, 32 px -->
<svg ... style="width:32px; height:32px; color:#153d64;" ...>

<!-- Inherits surrounding text colour automatically -->
<p style="color: darkred;">
  Error: <svg ...>...</svg> file not found.
</p>
```

To reuse the same icon multiple times without repeating the code, define it once in a hidden `<svg>` block at the top of your `<body>`, then reference it with `<use>`:

```html
<!-- Define once (hidden) -->
<svg style="display:none">
  <symbol id="icon-database" viewBox="0 0 24 24" fill="none"
          stroke="currentColor" stroke-width="2"
          stroke-linecap="round" stroke-linejoin="round">
    <ellipse cx="12" cy="5" rx="9" ry="3"/>
    <path d="M3 5v14c0 1.66 4.03 3 9 3s9-1.34 9-3V5"/>
    <path d="M3 12c0 1.66 4.03 3 9 3s9-1.34 9-3"/>
  </symbol>
</svg>

<!-- Use anywhere, as many times as needed -->
<svg width="24" height="24"><use href="#icon-database"/></svg>
<svg width="48" height="48" style="color:green;"><use href="#icon-database"/></svg>
```

## Tips

- Paste any HTML code directly into your `.html` files — no extra CSS or JavaScript needed.
- For emoji icons (codes starting with `&#12...` or `&#127...`), browser support is excellent on all modern devices.
- You can also paste the icon character itself (✓, ☰, etc.) directly into HTML — modern text editors and browsers handle Unicode fine.
- To change colour or size of an icon, wrap it in a `<span>` with inline style:
  ```html
  <span style="color: green; font-size: 1.2em;">&#10004;</span>
  ```
