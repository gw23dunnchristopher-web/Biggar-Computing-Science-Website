1. Short Text
Purpose: Names, addresses, phone numbers, codes
Max size: Up to 255 characters

Key Properties

Field Size — max number of characters allowed

Format — display formatting (e.g., > to force uppercase)

Input Mask — structured input (e.g., phone numbers)

Caption — label shown in forms/reports

Default Value — auto-filled value

Validation Rule / Text — restrict allowed entries

Required — must contain a value

Allow Zero Length — allow ""

Indexed — Yes/No/Duplicates OK

2. Long Text (Memo)

Max size: Up to 63,999 characters

Key Properties

Append Only — keeps history of changes

Text Format — Plain Text or Rich Text

Allow Zero Length

Format, Caption, Default Value, Validation Rule, Required
