End-User and Functional Requirements

During the analysis stage of website development, the following requirements should be identified.

End-User Requirements:

  • The end users are the people who are going to be using the website
  • Their requirements are the tasks they expect to be able to do using the website

Functional Requirements:

  • Processes and activities that the system has to perform
  • Information that the system has to contain to be able to carry out its functions

These requirements will help clarify the design of each webpage, identify the features to be implemented on the website, and evaluate whether the system is fit for purpose after development is complete.

Example of End-User and Functional Requirements

A band wants to develop a website for its fans. The site will provide details about the band, including biographies, music tracks, video clips and concert details.

End-User Requirements

Users should be able to:

  • navigate the site easily
  • view biographies and photos of band members
  • view all upcoming concerts and link to an external booking site
  • view video clips of the band
  • listen to the band’s audio tracks

Functional Requirements

The website must have:

  • a Home page should provide internal links to the topic pages (biographies, music, videos and concerts).
  • individual profile pages should include biography information, with photos of the band member and should have a link back to the Biographies page.
  • a Music page that should list the band’s albums and allow individual audio tracks to be played.
  • a Videos page that should list video clips and allow these to be played.
  • a Concerts page should list all the upcoming concerts, with links to the external booking site.
  • a link back to the Home page on all pages (except for the Home Page).
