SDD - The input() Function

Learning Intentions Success Criteria
We are learning about:
  • Writing code that asks the user to enter a value.
  • Storing a value entered by the user in a variable.
I am looking for you to:
  • Use the input() function to ask the user to enter a value.
  • Assign the value entered to a variable, both as a string and as an integer.
  • Write code that displays the value entered by the user in a message.

The input() function pauses the program and waits for the user to enter a value into the console. It only has one argument, which is the prompt that will be displayed to the user. For example, the code below will display the prompt "Enter your name: " and wait for the user to enter a value.

name = input("Enter your name: ")

Important things to note:

  • The prompt is enclosed in speech marks, so it is treated as a string.
  • Any value entered using input must be assigned to a variable so that the value can be used later. In this instance, the value entered was assigned to the variable name.
  • The value entered by the user is always treated as a string, even if it is a number.

Entering Integers

You can enter a number using the input function, but it will still be treated as a string. This means that you can't use it in arithmetic. Look at the example code below:

number1 = input("Enter the first number: ")

number2 = input("Enter the second number: ")

total = number1 + number2

print("The total is " + total)

If the user entered the numbers "4" and "5" here, then instead of the output being "The total is 9", it would be "The total is 45"! This is because the program would just be joining the two strings together, rather than adding the numbers.

So how can we have a program take in a number from the user? We have to convert the string to an integer by enclosing the input() function in an int(). This will take whatever we entered and convert it into an integer.

Things to remember:

  • You can only convert a string to an integer if it contains a number.
  • If you try to convert a string that contains a word to an integer, the program will crash.
  • Make sure that the number of opening brackets matches the number of closing brackets.
  • When displaying the an integer like the total here in a print function, make sure you convert it back to a string with str().
