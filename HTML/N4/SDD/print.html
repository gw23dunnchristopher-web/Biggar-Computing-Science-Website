Assigning a Value to a Variable

When we store a value in a variable, that is called assignment. In Python, assigning a value to a variable is very simple, you just use the '=' symbol. So, for example, typing apples = 4 would assign the value '4' to a variable called 'apples'.

You can also assign a value to a variable using the input() function, which we will look at later in this lesson.

It is wise to be mindful of what you assign to variables. If you want to assign a string of text, you will have to enclose the text you are assigning with speechmarks or inverted commas.

For example, name = "John" would be fine, but name = John would not.

Functions - print(), str() and int()

A function is a block of code that performs a specific task. In Python, functions are called using brackets, and can take arguments. For example, the print() function is used to display a message on the screen. It will display whatever is inside the parentheses.

For example, print("Hello World") will display the message "Hello World" on the screen. In this case 'print' is the function and "Hello World" is the argument.

The print function can only display either strings or integers, but not both. This is why 'Hello World' is enclosed in speech marks.

Concatenation

This is where you join two strings together. For example, if you wanted to display the message "Hello John", you could use the following code:

print("Hello " + "John")

What this does is take the "Hello " string and the "John" string and joins them together using the '+' symbol to make "Hello John"."

This is more useful when the values that you want to display are stored in variables. For example, if assigned the name 'John' to a variable called 'name', then you could use it like this:

print("Hello " + name)

This way, it would still display "Hello John", but if you changed the value of the 'name' variable, it would display whatever name you changed the value to. Note that the space after "Hello " is important, otherwise it would display "HelloJohn".

Type Casting

As mentioned in the previous lesson, computers are fussy about display two different datatypes using the same print function. Concatenation is the process of joining two strings together. You can't join a string and an integer together. So what do you do?

This is where type casting comes in! Python contains functions that change one type of data into another. Since we are using strings and integers, we will be using the type casting functions str() and int().

Function Description Example
str() Converts a value to a string. This is useful when you want to display a number as text. str(123) would convert the integer 123 to the string "123".
int() Converts a value to an integer. This is useful when you want to perform arithmetic on a string that contains a number. int("123") would convert the string "123" to the integer 123.

123 and "123" are not the same thing. 123 is an integer, and "123" is a string. You can't add them together, but you can convert one to the other.
