Testing

When we test a program, we are trying to make sure that it works as expected. There is a process to doing this:

  1. Get some test data to enter into the program.
  2. Think about and write down what we would expect to happen when we enter this data.
  3. Try entering the test data to see if the outcome matches our expectation.

At the N4 level, you will be given data with which to test your program, and you may need to create a testing table to show the expected output. Here is an example of a testing table for a program that asks the user to enter their age and displays whether they are old enough to vote (18 or over).

Test Number Input Expected Output Actual Output Pass/Fail
1 17 The program should display "You are not old enough to vote". The program displayed "You are not old enough to vote"." Pass
2 18 The program should display "You are old enough to vote". The program displayed "You are old enough to vote". Pass
3 -5 The program should display "Invalid age". The program displayed "You are not old enough to vote"." Fail

For each of the tests we did, first we wrote down what we expected the program to do, then we ran the program and wrote down what it's output actually was. If the actual output matches our expectations the program passes the test, otherwise it fails.

We can see here that the program failed the first test, so we would need to modify it so that it can pass this test (in this case by adding another condition to check if the input is less than 0).

Evaluation

After we have tested the program we need to evaluate it. This means looking at the functional requirements that we established in the Analysis stage, and then checking if the program meets all of those requirments. If it does meet all the requirements then it is considered to be Fit for Purpose.

Here's an example of the analysis of a program, together with its evaluation:

Analysis
Inputs Processes Outputs
The program will ask the user to enter the price of the meal and the price of the drink. The program will calculate the total cost of the meal by adding the price of the meal and the price of the drink. The program will display the total cost of the meal.
Evaluation

Does the program meet the requirements?

Yes, the program meets all the requirements. It asks the user to enter the price of the meal and the price of the drink, calculates the total cost by adding both values together, and displays the total cost of the meal.

Is the program fit for purpose?

Yes, the program is fit for purpose. It meets all the requirements and works as expected.

As you can see, your analysis of the program acts as a checklist to determine whether or not it is fit for purpose.
