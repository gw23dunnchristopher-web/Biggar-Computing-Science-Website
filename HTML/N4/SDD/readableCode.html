Why is readable code important?

When you are writing code, it is important that you make sure that it is readable. This means that you should make sure that your code is easy to understand and follow. This is important because it makes it easier:

  • to fix your code if there are errors.
  • for other people to understand your code (especially if you are working in a team).
  • for you to understand your code if you come back to it after a long time.

There are several ways that you can make your code more readable, including:

  • Using meaningful variable names
  • Adding internal commentary
  • Using consistent indentation
  • Using whitespace

We will now look at each of these.

Meaningful Variable Names

When you are writing code, it is important that you use meaningful variable names. This means that you should use names that describe what the variable is used for. For example, if you are storing the user's age, you should use a variable name like age rather than a.

When you read your code later, or if someone else reads your code, it will be much easier to understand what each of the variables you have created are used for.

For example, look at the following code:

a = 40

b = 25

c = 0.2


d = a * b

e = d * c

f = d - e


print(f)

In this version of the code, it is nearly impossible to tell what the program is actually calculating without reading every line carefully.

Now look at the following version of the same code:

hours_worked = 40

hourly_rate = 25

tax_rate = 0.2


gross_pay = hours_worked * hourly_rate

tax_amount = gross_pay * tax_rate

net_pay = gross_pay - tax_amount


print(net_pay)

In this version, the code explains itself. You don't need comments to understand the purpose of the calculation.

Tips for naming variables

  • You could use 'snake case', this is where underscores are used so seperate words in the variable name. For example: tax_code, height_in_metres, number_of_items.
  • You could also use 'camel case', this is where the first letter of each new word after the first is capitalised. For example: taxCode, heightInMetres, numberOfItems.
  • You should avoid using single letter variable names, unless they are used for a very short time, for example, in a loop.

Internal Commentary

Internal commentary is where you add comments to your code to explain what it does. This is important important for a couple of reasons - first, it makes it easier for you to read your code if you come back to it later. Second, for you in particular, it is necessary for your evidence because it shows that you understand what your code is doing.

There are two ways to write comments in Python:

  • Single line comments - these are written using the # symbol. Everything after the # symbol on that line will be ignored by the computer. These are usually used to expain what a single line of code or short block of code is doing.
  • Multi-line comments - these are written using ''' or """ at the start and end of the comment. Everything between the ''' symbols will be ignored. For your purposes you should use this to show your name, the name of your program, and the date you wrote it at the top of the code.

For example, look at the following code:

'''

Name: C Dunn

Program: Pay Calculator

Date: 27/03/2026

'''


# Get the number of hours worked

hours_worked = int(input("Enter hours worked: "))


# Get the hourly rate

hourly_rate = float(input("Enter hourly rate: "))


# Calculate the gross pay

gross_pay = hours_worked * hourly_rate


# Calculate the tax amount

tax_amount = gross_pay * 0.2


# Calculate the net pay

net_pay = gross_pay - tax_amount


# Display the net pay

print("Net pay: £", net_pay)

This way, you can easily tell what all of the code is doing. Also, you might note that the comments used here also work as pseudocode for the program!

Indentation

Indentation is where you use spaces or tabs to indent your code. This is important because it makes it easier to read your code. For example, look at the following code:

if age >= 18:

    print("You are old enough to vote")

else:

    print("You are not old enough to vote")

    print("You can vote in", 18 - age, "years")

This allows you to easily see which parts of the code are inside the if construct shown here.

You can see that if the user is 18 or over, the program will display that they are old enough to vote and if they are not, then it will show that they are not old enough to vote and display the amount of years it will be until they can vote. You can see what code will run for each condition easily thanks to indentation.

Using the Python coding language is useful for this, because it in Python the code will not run without correct indentation.

Whitespace

Whitespace is where you use spaces or blank lines to create spaces in between different sections of code. It breaks the code down into smaller segments and makes it easier to read. For example, look at the following code:

is_member = True

purchase_amount = 100


if is_member:

    discount = purchase_amount * 0.1

    final_price = purchase_amount - discount

    print("Discount applied!")


print("Thank you for shopping.")

Empty lines are used to separate different logical sections of your code. They don't affect how the program runs, but they make it much easier for a human to read. Think of them like paragraphs in an essay.
