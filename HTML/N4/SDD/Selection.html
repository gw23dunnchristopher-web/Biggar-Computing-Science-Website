What is Selection?

In programming, selection is a fundamental construct that allows a program to make decisions and follow different execution paths based on specific conditions.

As you know, a basic programming algorithm runs in a sequence. It executes the line of code at the top first, and then the one directly below it, all the way until it reaches the end of the script. Selection enables the program to be "intelligent" by choosing which code block to run next.

For example:

# Get the user's age

age = int(input("Enter your age: "))


# Check if the user is old enough to vote

if age >= 18:

    print("You are old enough to vote")

This program will ask the user to enter their age, and then display a message depending on whether they are old enough to vote or not. If the user enters 18 or greater as their age, then the program will display "You are old enough to vote". Otherwise, it won't display anything.

Boolean Logic

At its core, selection is governed by Boolean logic. In a computational environment, this means every decision is reduced to a binary outcome: the condition is either True or False. There is no middle ground or "maybe" in the CPU's logic gates.

Inclusive Boundaries

The distinction between "Greater than" (>) or "Less than" (<) and "Greater than or equal to" (>=) or "Less than or equal to" (<=) is important in logic design.

  • Exclusive (> and <): If you use if score > 100, the number 100 would return False. The logic only triggers starting at 101. Similarly, if you used if score < 0, then the number 0 would return false, so it would have to be a negative number for it to run the code.
  • Inclusive (>= and <=): If you use if score >= 100, then the number 100 would return True. The logic triggers at 100 and above. You could also use if score <= 0:, then the number 0 would return true, so it would run the code.

Just keep this in mind when creating your conditions.

Using Else

You can also use the else keyword to run a block of code if the condition is not met. For example:

# Get the user's age

age = int(input("Enter your age: "))


# Check if the user is old enough to vote

if age >= 18:

    print("You are old enough to vote")

else:

    print("You are not old enough to vote")

This program will ask the user to enter their age, and then display a message depending on whether they are old enough to vote or not. If the user enters 18 or greater as their age, then the program will display "You are old enough to vote". Otherwise, it will display "You are not old enough to vote".
