Arithmetic Expressions

Now that you are able to have the user enter data using the input() function, and can display messages using the output(). The next step is to have your program perform calculations. We do this using Arithmetic Operators, for example, look at the program below and see if you can guess what it does.

speed = int(input("Enter the speed:"))

time = int(input("Enter the time:"))

distance = speed * time

print("The distance travelled is " + str(distance))

This program asks the user to enter the speed of a moving object and the amount of time it has travelled, then works out the distance it has travelled by multiplying the speed by the time.

The symbol used for multiplication on a computer is a *. Here is a list of the arithmetic operators that Python uses:

Operator Name Example
+ Addition a + b would add the values of a and b together.
- Subtraction a - b would subtract the value of b from a.
* Multiplication a * b would multiply the values of a and b together.
/ Division a / b would divide the value of a by b.

Once, again, if you perform a calculation then that calculated value must be stored somewhere, so you need to assign it to a variable. In the example above, the calculated value was assigned to the variable distance.

This is also where we really need to take in inputs as integers, because you can't really perform arithmetic with strings.

Note that the division operator will always give you a decimal number, even if the numbers you are dividing are whole numbers. So if you divide 10 by 2, you will get 5.0, not 5.

Order of Operations

When you have multiple operators in an expression, you have to be aware of the order that the computer will complete these operations in. For example, look at the following expression:

a = 10 + 5 * 2

What do you think the value of a will be? If you said 20, you are correct, but why is it 20 and not 30? The reason is that the computer will always perform multiplication before addition. This is known as the order of operations.

The order of operations is as follows:

  1. Brackets
  2. Multiplication and Division
  3. Addition and Subtraction

So, if you want to perform addition before multiplication, you need to use brackets. For example:

a = (10 + 5) * 2

This will give you a value of 30.
