What is a fixed loop?

There are two types of loop that are used in programming - fixed loops and conditional loops. At the N4 level, we will focus on fixed loops.

Code is written in a sequence, meaning that the computer will read and execute the instructions from top to bottom, from the first line until the last line. However, there may be times when you want to repeat a section of your code over and over. This is what a fixed loop is for.

Fixed loops are used when you know exactly how many times you want to repeat a section of code. For example, if you want to ask the user to enter the marks for 10 students, you would use a fixed loop to repeat the code 10 times.

Look at the example below:

for x in range(10):

    mark = int(input("Enter the mark: "))

    print(mark)

This code will ask the user to enter a mark 10 times, and then display the mark that was entered.

Indentation

Note that the code below the loop is indented. This is to show which part of the code is inside the loop. Normally, if you press enter after typing the colon (:), Python will indent the code for you, and you can unindent it pressing backspace. You can create your own indents by pressing tab on the keyboard.

If you don't indent the code, the program will not run correctly.

Look at the example below, you can see which part of the code is inside the loop:

for x in range(10):

    mark = int(input("Enter the mark: "))

    print(mark)

print("The loop has finished")

Breaking down 'for x in range()'

The first line of the loop is the most important part. It tells the computer how many times to repeat the code. Let's break that line down so we know what each part of it does:

  • for - this tells the computer that we are starting a loop.
  • x - this is a variable that will be used to count the number of times the loop has run. It is needed for the loop to work. You can use it if you want to display this number. It starts at 0. It also doesn't have to be called x, you can call it anything you want, many people use 'i'.
  • in - this tells the computer that we are going to use a range.
  • range() - range() is a function that produces a range of numbers for the loop to go through, if you place the number 4 in the brackets it will produce the numbers 0, 1, 2, and 3. This will allow the loop to run 4 times, because there are 4 numbers (including 0).

Here is an example where I have used the x to ask the user to 'Enter student 1's mark:', 'Enter student 2's mark:', and so on:

for x in range(10):

    mark = int(input("Enter student " + str(x+1) + "'s mark: "))

    print(mark)

You can see that I have used str(x+1) to convert the number to a string, and I have added 1 to the number so that it starts at 1 instead of 0.
