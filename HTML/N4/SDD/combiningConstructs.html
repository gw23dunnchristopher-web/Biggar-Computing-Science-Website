Fixed Loops and Selection Statements Recap

The table below contains a recap of what we have learned

Construct Usage Code Example Result
Fixed Loop Used when you know how many times you want to repeat a block of code.

for x in range(5):

    print("Hello World")

This code will print "Hello World" 5 times.
Running Total Used when you want to add up a series of numbers.

total = 0

for x in range(5):

    total = total + 1

This code will add 1 to the total 5 times, so the total will be 5.
IF Statement Used when you want to check if a condition is true.

if number > 3:

    print("The number is greater than 3")

This code will print "The number is greater than 3" if the integer stored in a variable called 'number' is greater than 3.
IF...ELSE Statement Used when you want to check if a condition is true or false.

if number > 3:

    print("The number is greater than 3")

else:

    print("The number is less than or equal to 3")

This code will print "The number is greater than 3" if the integer stored in a variable called 'number' is greater than 3, otherwise it will print "The number is less than or equal to 3".

Nested Constructs

Nested if Statments

It is possible to place constructs inside other, constructs. This is called 'nesting' the constructs. You could, for example, place an if statement inside another if statement. As shown in the example below:

if number > 3:

    if number < 6:

        print("The number is greater than 3 and less than 6")

else:

    print("The number is less than or equal to 3")

This code will print "The number is greater than 3 and less than 6" if the integer stored in a variable called 'number' is greater than 3 and less than 6, otherwise it will print "The number is less than or equal to 3".

Note the indentation used here - the second if statement has been indented to show that it is inside the first if statement.

Nested Loops

Likewise, you can also place a loop inside another loop. Look at the example below:

for x in range(5):

    for y in range(5):

        print("Hello World")

This code will print "Hello World" 25 times. The first loop will run 5 times, and for each time it runs, the second loop will run 5 times. So, 5 x 5 = 25. You can see that the second loop has been indented so that it is clearly inside the first.

If statement nested within loops

You can also nest an if statement inside a loop. This is useful when you want to check a condition for each item in a loop. The example below is a program that asks the user to enter the temperature for each day of the week, and then shows the number of days that were above 20 degrees:

daysAbove20 = 0

for x in range(7):

    temperature = int(input("Enter the temperature for day " + str(x + 1) + ": "))

    if temperature > 20:

        daysAbove20 = daysAbove20 + 1

print("There were " + str(daysAbove20) + " days above 20 degrees")

This code uses a running total within a loop, but a selection statement has been added so that it will only add 1 to the total if the temperature entered was above 20.

Combining Constructs Questions

One of the questions below uses a trace table. A trace table is a way of tracking the value of a variable step by step as a program runs. You follow the code from top to bottom and record what the variable's value is after each step. This helps you check that your program is doing what you expect.

Here is a worked example. The code below counts how many numbers in a loop are greater than 1:

total = 0

for x in range(4):

    if x > 1:

        total = total + 1

We can trace through this code step by step, recording the value of total after each loop iteration:

x x > 1? total
0 No — condition is false, total stays the same 0
1 No — condition is false, total stays the same 0
2 Yes — condition is true, total increases by 1 1
3 Yes — condition is true, total increases by 1 2

After the loop finishes, total is 2, because only the values 2 and 3 were greater than 1.
