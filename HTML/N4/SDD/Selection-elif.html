Selection Recap

In the previous lesson, we looked at how to use IF and ELSE statements to make decisions in our programs. We saw that we can use IF statements to check if a condition is true, and if it is, we can run a block of code. If the condition is not true, we can use an ELSE statement to run a different block of code.

For example:

# Get the user's age

age = int(input("Enter your age: "))


# Check if the user is old enough to vote

if age >= 18:

    print("You are old enough to vote")

else:

    print("You are not old enough to vote")

This program will ask the user to enter their age, and then display a message depending on whether they are old enough to vote or not.

If the user enters 18 or greater as their age, then the criteria in the if statement will be 'true', because the value stored in age is greater than or equal to 18. The program will display "You are old enough to vote".

If the condition is not true, if the value stored in age is less than 18, then the program will display "You are not old enough to vote"

Using elif

However, some decisions have more outcomes than just being true or false. Sometimes you need to use more than just one criteria. For example, if you are grading an exam paper, then if the student gets 40% or more, they have acheived a D grade, but if they get 50% or more they have achieved a C grade. Further, 60% or more would be a B, and 70% or more would be an A.

In this case, you could use an IF statement to check if the student got 70% or more, and if they did, then you could display a message saying that they have achieved an A grade. However, if they didn't get 70% or more, then you would need to check if they got 60% or more, and if they did, then you could display a message saying that they have achieved a B grade, and so on.

To do this, you can use an ELIF statement. This stands for "else if". It allows you to check multiple conditions in a single IF statement. For example:

# Get the student's mark

mark = int(input("Enter your mark: "))


# Check if the student got 70% or more

if mark >= 70:

    print("You have achieved an A grade")

# Check if the student got 60% or more

elif mark >= 60:

    print("You have achieved a B grade")

# Check if the student got 50% or more

elif mark >= 50:

    print("You have achieved a C grade")

# Check if the student got 40% or more

elif mark >= 40:

    print("You have achieved a D grade")

# If none of the above conditions are true

else:

    print("You have failed the exam")

This program will ask the user to enter their mark, and then display a message depending on what grade they have achieved.

You can see that the program checks each condition in turn. If the first condition is true, then the program will display the message for an A grade. If the first condition is not true, then the program will check the next condition, and so on. If none of the conditions are true, then the program will display the message for a fail.
