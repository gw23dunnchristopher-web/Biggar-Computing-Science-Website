BHS Computing Science

National 4

ISDD - Unit Outcomes

Outcome 1

The candidate will...

  1. Explain how simple programs work, drawing on understanding of basic concepts in software development by:
    1. Reading and explaining code.
    2. Identifying the purpose of a range of programming constructs and how they work.
    3. Identifying the purpose of a range of variable types.

The range of programming constructs should include expressions, sequence, selection and iteration.
Outcome 2

The candidate will...

  1. Develop short programs using a software development environment by:
    1. Selecting and using combinations of appropriate constructs.
    2. Selecting and using appropriate simple data types, such as numeric (integer) and string.
    3. Testing digital solutions using supplied test data.

The range of programming constructs should include expressions, sequence, selection and iteration.

Programs should include at least one construct and one data type.
