The first stage of software development is analysis. This is where we look at the problem we are trying to solve and figure out what we need to do to solve it. Here, we need to define the Functional Requirements of the program - what data needs to be entered into it, what it will do with that data, and what it will output.

Functional Requirements

These describe what the program needs to be able to do in order to fulfil its purpose. At this level, you should be able to look at a problem, and define the inputs, processes and outputs for the program.

Input(s) The data that needs to be entered into the program, for example, in a program adds two numbers together, the inputs would be the two numbers that you want to add.
Process(es) The steps that the program needs to take to achieve its goal. For example, in a program that adds two numbers together, the process would be to add the two numbers together.
Output(s) The data that the program will produce as a result of its processes. For example, in a program that adds two numbers together, the output would be the sum of the two numbers.

The functional requirements are the foundation of the program. They define what the program needs to do, and without them, you won't be able to design or build the program.

A worked example

A good way of determinine the functional requirements are to look at the action verbs in the question, which indicate the actions that need to be taken by the program, and the nouns, which indicate different variables that will need to be stored.

Calorie Counter

  • Calculates the total number of calories in the breakfast.
  • Displays the total number of calories.

With this, we can identify the inputs, processes and outputs for this program.
