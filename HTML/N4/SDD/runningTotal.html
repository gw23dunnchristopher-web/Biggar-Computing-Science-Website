What is a running total?

A running total is a standard algorithm that is often used in programming. It is used when you want to add up a series of numbers and keep a running total of the sum. For example, you might use a running total to calculate the total cost of items in a shopping cart, or the total number of votes.

To create a running total, you need to:

  1. Create a variable to store the running total. This variable should be initialised to 0 before the loop starts.
  2. Create a loop that will run a set number of times.
  3. Inside the loop, add the value of the current item to the running total.
  4. After the loop has finished, display the running total.

Example

Here is an example of a program that uses a running total to calculate the total cost of items in a shopping cart:

# Initialise the running total

total = 0


# Loop 5 times

for i in range(5):

    # Get the price of the item

    price = float(input("Enter the price of the item: "))


    # Add the price to the running total

    total = total + price


# Display the total

print("The total cost is: £", total)

This program will ask the user to enter the price of 5 items, and then display the total cost of all the items.

You can see that the variable total is initialised to 0 before the loop starts. This is important, because if you don't initialise the variable, the program will crash when it tries to add the first number to the running total.

The variable is then updated inside the loop, using total = total + price. This might seem odd, but when you reach that point the first time, the total is 0, so it is setting the total to the number you entered plus 0. If you typed in 5, then the next time the loop runs it will set the new total value to 5 plus the new number you type in.

Rather than using total = total + price, you could also use total += price. This does exactly the same thing. For example:

# Initialise the running total

total = 0


# Loop 5 times

for i in range(5):

    # Get the price of the item

    price = float(input("Enter the price of the item: "))


    # Add the price to the running total

    total += price


# Display the total

print("The total cost is: £", total)

This is a shorthand way of writing the same thing. It is often used in programming, because it is shorter and easier to read.
