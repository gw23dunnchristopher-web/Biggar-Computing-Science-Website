ISDD - Unit Outcomes

Outcome 1

The candidate will...

  1. Develop a simple Information System, using appropriate development tools by:
    1. Creating a structure and links.
    2. Integrating different media types (images, text, video, audio).
Outcome 2

The candidate will...

  1. Consider a number of basic factors involved in the design and implementation of an information system by:
    1. Describing its basic features and functionality.
    2. Describing its hardware, software, storage and connectivity requirements.
    3. Describing relevant security risks.
