What is a database?

Any large amount of information must be stored in some sort of order so that can be accessed quickly and easily.

A database is a structured collection of similar information.

Databases can be stored manually (filing cabinets, index cards) or electronically, using a computer system.

A program that is used for organising data on a computer system is called a database package or database management system.

Typically, in High School, we use Microsoft's Access program to practice using databases. However, I have included a small program on this website that you can use. It is very similar to Access.

Database Structure

Think about a filing cabinet, the old kind of database before we moved onto electronic databases. Each filing cabinet contains files, they look a bit like folders. Inside the files are records - each record contains information on one person or thing in the database. Each record consists of a list of different bits of information on the person or thing that the record is about.

Electronic databases are structured in almost exactly the same way - in Files, Records and Fields.

  • File - A file is a collection of similar records. For example, a file of pupil records, or a file of staff records.
  • Record - A record is a collection of fields that contain information about one person or thing. For example, a record of information on one pupil, or a record of information on one staff member.
  • Field - A field is a single piece of information in a record. For example, a pupil's name, or a pupil's date of birth.

Microsoft's Access program gives slightly different names to these. In Access, a file is called a table, a record is a row in the table, and a field is a column.

Electronic Database vs Paper Database

There are a large number of benefits to using an electronic database over a paper database:

  • Speed - Databases can contain a lot of information, a computer can search through or sort the records in large databases much faster than a human can.
  • Security - Electronic databases are much less likely to be damaged than paper databases. They are also much less likely to be stolen.
  • Efficiency - When they are uploaded to the internet, electronic databases can be accessed from anywhere and can be shared with other people.
  • Easy to update - It is much easier to add new records, remove records or update records in an electronic database.
  • Easy to backup - Electronic databases can be backed up to a USB stick or a cloud storage service. This means that if the database is damaged, it can be easily restored.
