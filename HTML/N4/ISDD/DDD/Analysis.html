Database Analysis

Learning Intentions Success Criteria
We are learning about:
  • Analysing a problem to make a database.
I am looking for you to:
  • Explain what end user requirements and functional Requirements are in terms of databases.
  • Describe end-user requirements for a simple problem, and the functional requirements of the required database.

Before we create a database we need to figure out what our database is going to be for - in the case of your N4 work, you'll be given a problem that you'll need to make a database to solve, and you'll have to look at the question and think about what kind of database you need to make. In the analysis phase, we need to identify both the end-user and functional requirements of the database.

End-User Requirments

The people who will be using your database are called the end users. There will be a list of tasks that they will want to carry out using your database, tasks that they will require your database to do. These are called end user requirements.

Here's an example of a question that you might be given for your N4 work, and the end user requirements for the database that you would need to make:

Question: A school wants to create a database to store information about its pupils. The database should store the pupil's name, age, and class. The school wants to be able to search for pupils by name, and to display a list of all pupils in a particular class.

End User Requirements:

  • The end-users want to store information on each student, including their name, age, and class.
  • The end-users want to be able to find a pupil by searching for their name.
  • The end-users want to be see a list of all of the students in a particular class.

You can see here that the end-user requirements are what the end-users want to be able to do with the database. What information they want to store and what tasks they want to be able to do.

Functional Requirements

The functional requirements of a database are the specific functions that the database must be able to perform to meet the end-user requirements. They are the tasks that the database must be able to do to allow the end-users to carry out their tasks.

Here's an example of the functional requirements for the database that you would need to make for the question above:

Functional Requirements:

  • The database must be have fields for the pupil's name, age, and class.
  • The database must be able to perform a simple search for pupils by name.
  • The database must be able to display a list of all pupils in a particular class.

You can see that while the end-user requirements are all from the perspective of the people using your database, the functional requirements are all about what tasks the database itself needs to be able to do.
