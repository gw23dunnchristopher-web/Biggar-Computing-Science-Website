Adding and Deleting Records

  • Build a database from a data dictionary and then populate it with records.

In this section, we are going to look at how to add and delete records from a database. In Access this is all done in the Datasheet View.

Adding Records

To add a record to a database, you need to be in the Datasheet View. You can then type in the data for the record in the appropriate fields. You can see an example of this below.

This is the customer database from the previous page.

If you start entering data into the fields, you can see that a new blank record will be created below the one you are entered. Adding records to a database like this is called 'populating' the database.

Deleting Records

To delete a record from a database, you need to be in the Datasheet View. Right-click on the record (row) that you want to delete and select the Delete Record option. This will remove the record from your database.

Note that if your record has an autonumber field, that number will not be reused if you create a new record.
