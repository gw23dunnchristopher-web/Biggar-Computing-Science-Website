Using this program is very similar to using Microsoft Access.

Opening Access and Creating a New Database

To open Access, perform the following steps:

  1. Type Access into the search bar in the bottom left hand corner of the screen.
  2. Click on the Microsoft Access Icon.
  3. In the window that opens, click on Blank Database.
  4. Type in the name of your database and click Create.

Datasheet and Design View

In Access, there are two different views that you can use to work with your database. The Design view and the Datasheet view. You can switch between them by clicking on the icon in the top left of the Access window. Below is an explanation of the two views (I have included what the view looks like both in access and in my app below):

View Function Access Icon App Icon
Datasheet View The Datasheet View is used to enter data into the database. It is the view that you will use to add, edit and delete records.
Design View The Design View is used to design the database. It is the view that you will use to add, edit and delete fields.

You will notice that when you create a new database, you will start in the Datasheet View. The first thing you need to do is click on the icon for the Design View.

Once you click on the Design View icon. You will see the window below - Access will ask you to name the table.

After you give the table a name, it will take you to the design view.
