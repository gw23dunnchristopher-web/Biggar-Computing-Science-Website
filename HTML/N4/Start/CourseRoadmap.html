N4 Units

To earn your full National 4 qualification, you must complete three distinct parts. Think of these as the building blocks of the course. There is no final external exam; instead, you pass by completing practical tasks and showing you understand the concepts.

1. Software Design and Development (SDD)

This unit is all about problem-solving. You will learn how to think like a programmer and turn your ideas into working code.

  • What you'll learn: How to design programs using flowcharts, write code (usually in Python), and test it to make sure it works.
  • How you'll pass: You’ll complete a series of small coding challenges and a final practical task where you create a program from scratch.

2. Information Systems Design and Development (ISDD)

This unit looks at how the digital world is built and managed. It’s split into two main practical areas: Websites and Databases.

  • What you'll learn: How to build webpages using HTML and CSS, how to organize data in databases using SQL, and how computers keep our information secure.
  • How you'll pass: You will create a functional multi-page website and a working database, explaining how you kept the data safe and legal.

3. The Added Value Unit (AVU)

This is your "Grand Finale." It is a large, independent project that pulls together everything you’ve learned in the first two units.

  • What you'll do:You will be given a "Problem Brief" (like creating a digital system for a sports club or a shop). You will design, build, and test the entire solution yourself.
  • Why it matters: This is the final requirement for the National 4 award. It proves you can apply your skills to a real-world scenario without a teacher holding your hand.

Because N4 is "Pass/Fail", your goal isn't to get 100% on a test - it's to provide evidence that you can do the work. Save every version of your code and every screenshop of your designs!

N4 Checklist

This is a checklist for everything that you will need to know for N4, by clicking on the link below you will be able to download a copy of this file for yourself, when you complete each section on the website, check off that part of the table.

N4 Checklist
1. Software Design and Development (SDD)
Design I can use a simple design (like a flowchart or structure chart) to plan a program.
Data Types I can use variables to store Text (String) and Numbers (Integer).
Input/Output I can get data from a user and display a message back.
Arithmetic I can make the computer do math (+, -, *, /).
Selection I can use if statements to make the program make decisions.
Repitition I can use a fixed loop to repeat code a set number of times.
Testing I can show that my program works by testing it with "normal" data.
Explanation I can describe how my code works using terms like variable and loop.
  
2. Information Systems Design and Development (ISDD)
Database Skills (MS Access)
Design View I can create a table and set Field Names
Data Types I can assign the correct types (Short Text, Number, Dat/Time, Yes/No)
Primary Key I can identify and set the unit field (the 'Gold Key).
Amending Data I can Add a new record, Edit an old one, and Delete a record.
Queries I can use the Query Design tool to:
Search: Use the criteria info to find records containing a specific value.
Sort: Order records by one field in ascending or descending order.
Web Development Skills
Analysis I can identify the Target Audience and the Purpose of the site.
Design I can create a Site Map (Structure Chart) showing how pages link together.
I can draw Wireframes for each page showing the layout of text and   images.
Implementation I can use the following tags: <html>, <head>, <title> and <body>
I can add content using the following tags <h1>, <p> and <img>
I can add Internal Links (to my pages) and External Links (to other websites) using an anchor tag - <a>
I can use CSS to change background colours, text colours and font styles.
Media and Testing I can explain why I used JPG/PNG (Compression) to keep file sizes small.
I have tested that every link works and the layout matches my wireframes.
Computer Systems
I can identify the CPU, RAM, Input/Output devices and Storage
I am aware of security threats online, and know how to defend against them.
  
3. Added Value Unit (AVU)
Analysis I have identified the functional requirements of my program/information system (What it must do).
Design I have designed my system using a recognised design technique (pseudocode, flowcharts, wireframes, etc).
Implementation I have created my program using a high level programming language (Python).
I have created my information system in a suitable program (MS Access, Notepad++, Pheonix Code).
Testing I have tested my system using the data provided, and taken screenshots of the tests.
If there were any errors I fixed them.
Reporting I have checked my project against the original analysis and can explain how it meets the requirements.
I can describe how I would improve the information system I've created.
I can describe any problems or difficulties I had in while doing this project and how I resolved them.
