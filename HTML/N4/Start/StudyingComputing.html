How to study N4 Computing

Computing Science is a practical subject. You don't learn it by reading about it, you learn it by doing it. Throughout this course you will write code, design websites and create databases. You'll also see a lot of errors, have to do a little bit of research to find out what they mean, and then fix them. This is all part of the process of learning to code.

Learn, Try, Prove

To move through this course successfully, there are three steps you must take for every new topic:

  • Learn - You'll read through a section of the website, and perhaps watch a short video. Before you move on, you should try to explain the idea to a friend or to your teacher.
  • Try - You will be given some tasks to complete. These aren't for your grades, they're to help you learn. If the code breaks here and you get a lot of errors, it doesn't matter! Working out how to fix them yourself will improve your coding in the long run.
  • Prove - Once you feel condfident, you can taken on the final task of the section. This is an 'evidence' task, which will be used to show that you have mastered that particular aspect of the course. If this task involves coding, you will have to screenshot your code and keep it as evidence.

Getting Unstuck - How to fix your code

Whether you are coding in Python or creating a website, you will run into errors eventually. You can always ask the teacher for help, but before you do, try to solve the problem yourself by following these steps:

  1. Check your code - An awful lot of errors are caused by simple spelling mistakes or missing out essential characters. Did you miss a colon (:) in Python? Did you forget to close a tag in HTML? It's important to read your own code carefully first.
  2. Read the Error Message - When something goes wrong, the computer will give you an error message. This will tell you what went wrong and where. Check the line that it says the error is on, as well as the line immediately before it.
  3. Look up the Error - You might need to do a little research yourself, you can look up the error on google and find out what it means, or you could look at some of the sample errors on this website.

Work on the problem yourself for at least 10 minutes before you ask for help. The more you tried, the more you will have learned by trying!

Computational Thinking

One of the most important skills you will learn when studing Computing Science is computational thinking - the ability to solve complex problems by breaking them down into simple steps. There are four parts to computational thinking: decomposition, pattern recognition, abstraction and algorithms.

  • Decomposition

    Breaking a big project (like creating a website) into smaller, manageable pieces (like adding text or adding images).

  • Pattern Recognition

    Noticing certain pieces of code are almost the same, so you can use them over and over with small adjustments.

  • Abstraction

    Focusing on the important parts first. For example, if you are making a game, you want to make sure the game works before thinking about how it looks.

  • Algorithms

    Creating a set of steps to solve a problem. For example, if you want to find the largest number in a list, you could write an algorithm to compare each number to the next one and keep track of the largest one.

Building your portfolio

Since there is no exam, you have to take care that you always save your work, and that you use good file names.

  • Make sure that you name your files clearly! For example, instead of 'doc1.png' use 'N4-SDD-Program1 - print.png'.
  • Annotate your work! Using internal commentary is a requirement of N4 Computing Science. If you add comments to your code (use # in Python) then you will be able to explain what that section does. This will prove to the SQA that you wrote it and understand it.
