Programming Tools

There are many different programming languages out there that you could use to complete your work in N4 Computing Science. At Biggar High School we use Python because it is a powerful, yet beginner-friendly language that is used by professional developers worldwide and is an industry standard.

To write and run your own Python code you will need an IDE (Integrated Development Environment). There are many different IDEs available, and all of them have different features, but on the computers in school we use Thonny.

There are a number of different IDEs that you can get for free at home (including Thonny!) please look at the links below to download the one that you want to use.

Download Links

  • Thonny - The code editor that we use in school.
  • Visual Studio Code - A commonly used IDE that can code in both Python and HTML.
  • Built-in Code Runner - This website includes an interactive code runner on lesson pages, allowing you to run Python and HTML code directly in your browser without needing to install anything.
  • PyCharm - Another common IDE, this one is AI-enhanced.
  • Python IDLE - The base IDE that comes packaged with Python installs, it has limited features.

Web Development Tools

In order to code webpages, you need software that is capable of writing HTML (Hypertext Markup Language) and CSS (Cascading Style Sheets). The both of these are really just text files with the .html and .css file extensions. This means that you can edit web pages using any program capable of editing text. However, most of these programs don't highlight the different tags and pieces of code used in HTML!

Using the right program to HTML can make the process a lot easier, some of them have a preview of how your web pages will look, and others even autocomplete parts of your code. In Biggar High School, we use a piece of software called Phoenix Code to edit web pages. This can either be downloaded or just used online.

There's a list of free text editors designed with web coding in mind below.

Download Links

  • Phoenix Code - The code editor that we use in school.
  • Visual Studio Code - This can also be used for HTML coding.
  • Sublime Text - A lightweight text editor that is popular with web developers.
  • Notepad++ - A free text editor that is a little more advanced than the default Notepad on Windows.

Database Development Tools

While there is a lot of different brands of software available for manipulating databases, there are very few free options. For the N4 level, we will be using Microsoft Access, since it is part of the Microsoft Office suite and is therefore available through GLOW.

Access is useful for beginners because it has a graphical user interface - you can click on the different cells of the tables and create queries without having to use SQL (Structured Query Language). For higher levels, it still has an SQL feature, where you can type in the code to manipulate the database directly.

It should be noted, however, that Access only works on Windows, it won't work on Chromebooks, Macs or iPads. If you don't have windows, I have provided links to some free alternatives below.

Download Links

  • Microsoft Access - The database software that we use in school.
  • LibreOffice Base - A free alternative to Access that works on Windows, Mac and Linux.

Note: If you are using a Chromebook, you will need to use the online version of Access through GLOW.

File Management

It's important to keep all of your files in order as you go through this course. Create a N4 Computing folder in a space in your OneDrive or on your computer and, inside that folder create the following subfolders.

  • Unit 1 - SDD - You will save all of your Python files into this folder.
  • Unit 2 - ISDD - This folder will contain two more folders.
    • Web Development - All of your HTML and CSS files will be saved here.
    • Database Development - All of your Access databases will be saved here.
  • AVU - This folder will contain all of the files that you create for your AVU.

It is important that you know where everything is just in case you need to refer to it later, or use if for evidence. Remember, all of the projects in N4 Computing Science are open book, so there is no problem with going back and using code from your previous programs.
